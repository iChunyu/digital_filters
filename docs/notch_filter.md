# Notch 二阶陷波（notch_filter）

**源文件**：`include/notch_filter.h`、`src/notch_filter.c`
**测试**：`tests/test_notch.c`（标定表、回归档位与实测统计只在此维护，本文只给结论与指针）

固定二阶、单节、无类型与阶数变体的陷波器。设计路径是全库最短的一条——预畸 →
双线性 → 直接写一个 `biquad_filter_t`，不走 `docs/filter_utils.md` 的零极点管线。
知识密度集中在两处：参数闸的**预测式**性质，以及 f32 量化在深陷波上的代价。

## 传递函数与参数语义

$$
H(s) = \frac{s^2 + 2\xi g \omega_0 s + \omega_0^2}{s^2 + 2\xi \omega_0 s + \omega_0^2},
\qquad \omega_0 = 2\pi f_0
$$

$\omega_0$ 是陷波中心角频率，$g \in (0, 1)$ 是陷波深度，$\xi > 0$ 是带宽因子。
分子分母只在 $s$ 的一次项上不同：**零点阻尼 $\xi g$（窄）对极点阻尼 $\xi$（宽）**。
零点贴近 $j\omega$ 轴挖出谷底，极点把它托回 0 dB，因此陷波的尖锐度全部来自零点。

在 $s = j\omega_0$ 处分子分母的 $s^2$ 项与常数项分别相消，只剩 $\xi g$ 与 $\xi$ 之比：

$$
|H(j\omega_0)| = g
$$

直流与高频增益都是 1：$H(0) = H(\infty) = 1$ 在 $s$ 域直接可见，双线性之后对应
$b_1 = a_1$、$b_0 - 1 = -(b_2 - a_2)$，在 $z = \pm 1$ 处分子分母逐项相消。这条
**结构保证**是后面"下游察觉不到坏设计"那句话的前提。

## 对象与 API

`notch_filter_t` 只有 6 个标量字段（`valid`、`num_sections`、`f0`、`xi`、`g`、`fs`）
加一个内嵌的 `biquad_filter_t sections[1]`（`num_sections` 只能是 0 或 1）。三入口是
`notch_init` / `notch_update` / `notch_reset`：`_update` / `_reset` 是头文件
`static inline`（每样本零函数调用），`!valid` 时 update 原样返回输入、reset 为空操作。

Notch 与 Peak 都固定二阶、没有阶数与类型族，所以**不用 X-macro**——Butterworth /
Chebyshev 那套 `FOR_EACH_*_ORDER` 在这里只会把一个结构体写得更绕。热路径无
NaN/Inf 防护、不可重入（ISR 与主循环共享同一对象时需关中断或双缓冲），理由与
biquad 层一致，见 `docs/biquad_filter.md` 的「热路径 static inline」。

## 设计流程：预畸 → 双线性 → 直写单节

1. **参数闸**（见下节的第一步）。
2. **预畸**：$w_0 = 2\pi \cdot \mathrm{prewarp}(f_0, f_s)$，即
   $w_0 = 2 f_s \tan(\pi f_0 / f_s)$。记 $K = 2 f_s$，则归一化频率
   $r = w_0 / K = \tan(\pi f_0 / f_s)$ 恰好是双线性代换 $s = K\frac{1 - z^{-1}}{1 + z^{-1}}$
   自带的那个量——判据复用它，不引入额外 `libm` 调用。
3. **s 域系数**（升幂 $[s^0, s^1, s^2]$，与 `biquad_c2d_bilinear` 的入参约定一致）：
   `num_s` $= [w_0^2,\; 2\xi g w_0,\; 1]$、`den_s` $= [w_0^2,\; 2\xi w_0,\; 1]$。
4. **双线性** `biquad_c2d_bilinear` → 得到 `num_z` / `den_z`（`den_z[0]` **未归一化**）。
5. **部署** `biquad_filter_init`：归一化 + 三道闸（系数有限性、Jury、极点半径裕量），
   失败即替换为单位直通并返回 0。
6. **增益校验** `check_cascade_gains(..., 1.0f, 1.0f)`：DC 与 Nyquist 期望都是 1。
   这是结构保证，保留此闸只为与另两族同构，并兜住粗粒度算错。

### 为什么不走 `design_filter` / `zpk2sos`

`zpk2sos` 解决的是"$n$ 个零极点怎么分组、谁和谁配对"，而二阶节的零极点本来就恰好
组成一个分子分母对——**配对问题在选择之前就不存在**。走管线要多付：容量边界闸
（`np` / `nz` 上限）、实/复分类与共轭认领盒两个容差、两条配对收尾不变量、三式增益
折叠，全是 $n \ge 2$ 才需要的东西，收益为零。直写路径只剩两个失败点：双线性的
数值（由 `biquad_filter_init` 兜住）和 `biquad_filter_init` 自身。

### 预畸只保住中心与深度

预畸让 $\omega_0$ 精确落在 $f_0$ 上、$|H| = g$ 精确落在谷底，代价是双线性变换对
整个频率轴**非线性**：数字域的陷波宽度是 $2\xi g f_0$ 再乘一个随 $f_0/f_s$ 变化的
扭曲因子（预畸本身只保证被指定的那一个频率点对齐，见 `docs/filter_utils.md` 的
「预畸」）。

由此得两条约定：$\xi$ 始终按**模拟原型**的带宽因子解释，不随 $f_s$ 重标定；改采样率
只改扭曲因子，不改 $\xi$ 的语义。

## 三道闸

任一闸失败即置 `valid = 0` **且** `num_sections = 0`（两者都被显式清零），调用方
按直通处理：

1. **参数闸**：$f_s > 0$、$0 < f_0 < f_s/2$、$\xi > 0$、$0 < g < 0.9999$。一律写成
   `!(x > 0)` 而不是 `x <= 0`——后者与 NaN 比较恒假，会把 NaN 放行。
2. **f32 设计参数范围闸**：$\xi g (\omega_0/K)^2 \ge 5\times10^{-8}$（下一节）。
3. **逐级 fail-closed**：`biquad_filter_init` 的系数有限性 / Jury / 极点半径裕量，
   加 `check_cascade_gains` 的 DC/Nyquist 窗口。

`num_sections` 必须显式清零：调用方可能漏检 `valid`，垃圾节数会让后续按节数遍历的
代码读到越界节。清成 0 后 0 节级联天然直通；`_update` 另有 `!valid` 判据先返回输入。

## 预测式参数闸 $\xi g (\omega_0/K)^2 \ge 5\times10^{-8}$

$K = 2f_s$。低于阈值时谷底静默变浅、中心偏移，而**下游察觉不到**：在被拒的参数上求
$|H(j\omega_0)|$ 本身就是那个病态运算，求出来的数不可信；而 DC/Nyquist 增益无论设计
多坏都精确是 1（$z = \pm 1$ 处逐项相消，结构保证），`check_cascade_gains` 的窗口
看不出任何异常。所以这道闸只能**按参数判**，且必须在设计之前判——它不是"设计完再
看一眼响应"的事后检查，而是对已知会失真的参数直接摇头。被拒的参数**不是**被修好或
被补偿，只是不再点头；需要深度失真的调用方可以绕过族 API，直接用
`biquad_c2d_bilinear` 自己造系数。

**反直觉但有物理意义**：判据与 $g$ 成正比，所以同样的 $f_0$ 下**浅**陷波（$g$ 大）
反而更容易过闸。浅陷波的分子分母差异大、需要相消的位数少，f32 承载得住；深陷波才是
难的那一端。（Peak 族正好镜像，见 `docs/peak_filter.md`。）

**标定口径**：阈值在 $f_0$ 的 ±1% 邻域上取最坏值，不能采孤立点——失效在 0.002 Hz
尺度上剧烈震荡，那些"好"的值只是舍入运气好，按孤立点标定会得出乐观得多的阈值。
标定表与可重跑的邻域回归见 `tests/test_notch.c` 的「数值闸边界：Q = xi\*g\*(w0/K)^2
跨过 5e-8」段与「回归：把上面那段邻域标定变成可重跑的测试」段。

### 两条闸的先后：数值闸通常更紧

以 $r = \tan(\pi f_0/f_s)$ 计，两道闸的阈值分别是
$r_q = \sqrt{5\times10^{-8}/(\xi g)}$（数值闸）与 $r_r = 2.5\times10^{-5}/\xi$
（极点半径裕量闸，见 `docs/biquad_filter.md`）。$r_q > r_r \iff \xi > 0.0125\,g$，
所以在绝大多数参数下**数值闸才是先触发的那道**——与 Peak 相反，因为这里的极点阻尼
是 $\xi$，与 $g$ 无关。

## 浅到等同不陷波：$g \ge 0.9999$ 按直通部署

$g \ge 0.9999$ 时陷波浅于 0.001 dB（$g = 1$ 即分子分母逐项相等、$H \equiv 1$），
这是数学上的恒等，按直通部署（`valid = 0`）比烧一个高 Q 节划算。判据写成
`g >= NOTCH_G_MAX`，$g = 0.9999$ 本身即拒。

## reset 与 $w_{ss}$ 量级

陷波 DC 增益为 1，稳态状态量 $w_{ss} = e/(1 + a_1 + a_2)$：$f_0 = 20$ Hz、
$f_s = 48$ kHz 时约 $1.5\times10^5 e$（$e$ 是 `reset` 的常值输入）。复位后最初几个
输出在 f32 下带绝对误差，随后收敛——这是"DC 增益 1 + 中心频率很低"两条并存的
**结构固有**结果，不是 bug，别去修。守卫（分母为零/非有限、$w_{ss}$ 溢出 → 清零
状态，永不产生 inf/NaN）在 `biquad_filter_reset` 层，见 `docs/biquad_filter.md`
的「reset 契约」。

## 已知边界：被拒是预期行为

- **极窄带 / 近 DC / 近 Nyquist** 的设计返回 `valid = 0`（直通）：主因是 f32 系数
  量化让谷底与中心失真（有时是极点半径裕量），不是算法错误。边界**非单调**，相邻
  一小段频率里 `valid` 会翻转，一律以 `valid` 为准，不要用解析公式预测可用区间。
- **被拒 ≠ 静默失真**：这道闸的意义正是"不在明知会失真时还点头"（见「预测式参数
  闸」）。
- 该深度闸在 $g$ 接近 1 且 $\xi$ 很小时不再是先触发的那道，此时**半径裕量闸**先拒
  （$\xi < 0.0125\,g$ 一侧），实测档位见 `tests/test_notch.c` 的「数值闸边界」段。

## 测试指针

标定表、回归档位与实测统计只维护在 `tests/test_notch.c`（本文只给结论与指针）：

- 「基本设计：fs=1kHz, f0=50Hz, xi=0.05, g=0.1」、「深度扫掠」、
  「频率扫掠：全落在闸内，且必须全部精确」、「xi 扫掠」——深度 $\approx g$、
  DC/Nyquist 精确为 1、以及"窄带而非宽带衰减"三条语义；
- 「数值闸边界：Q = xi\*g\*(w0/K)^2 跨过 5e-8」——阈值标定（邻域最坏值口径）、
  "浅陷波更容易过闸"的两侧档位、闸外只钉 fail-closed 这一半；
- 「回归：把上面那段邻域标定变成可重跑的测试」——把邻域标定变成断言；
- 「g 上限：浅到等同不陷波 → 直通」——$g = 1$ / $g = 0.9999$ 与 $g = 0.999$ 的边界；
- 「参数闸：非法输入一律 valid=0 且 num_sections 清零」——含 NaN / +Inf 的
  `!(x > 0)` 行为与直通；
- 「reset：DC 稳态」——`reset(0.5)` 后输出 $\approx 0.5$、非有限 equilibrium
  不得毒化状态。

## 为什么不这样写（被否方案）

- **走 `design_filter` / `zpk2sos`**：二阶节没有配对问题，多付容量闸、两个容差、
  两条收尾不变量与增益折叠，收益为零（见上）。
- **$g \ge 0.9999$ 也烧一个节**：数学上就是恒等（浅于 0.001 dB），高 Q 节只换来
  数值风险。
- **拿 $|H(j\omega_0)|$ 的求值结果当闸**：在被拒的参数上那个求值本身就是病态运算，
  且 DC/Nyquist 恒为 1 掩蔽了一切——只能按参数判、且必须设计前判。
- **入口闸写 `x <= 0`**：NaN 比较恒假，会把 NaN 放行到 `tanf` 与系数计算。
