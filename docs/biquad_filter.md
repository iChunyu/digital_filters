# biquad 二阶节（biquad_filter）

**源文件**：`include/biquad_filter.h`、`src/biquad_filter.c`
**测试**：`tests/test_biquad.c`（标定表、回归档位与实测统计只在此维护，本文只给结论与指针）

二阶 IIR 节的唯一实现（直接 II 型／规范型）。Butterworth / Chebyshev 的每个
`sections[]` 节、以及 Notch / Peak 的单节都由它部署与推状态；六个公开头也都包含
`biquad_filter.h`，它因此是 `-ffast-math` 编译期守卫的唯一公共顶点。

## 结构

直接 II 型只用 3 个状态变量，是二阶节最省内存的形式：

$$
H(z) = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2}}{1 + a_1 z^{-1} + a_2 z^{-2}}
$$

`biquad_filter_t` 三个字段：

- `num_z[3]`：分子系数 $b_0, b_1, b_2$；
- `den_z[3]`：分母系数 $1, a_1, a_2$；
- `w[3]`：状态 $w[n], w[n-1], w[n-2]$。

状态方程与输出为 $w[n] = x[n] - a_1 w[n-1] - a_2 w[n-2]$、
$y[n] = b_0 w[n] + b_1 w[n-1] + b_2 w[n-2]$。`w[0]` 是最新中间值 $w[n]$，`w[1]` /
`w[2]` 是前两拍；`update` 先快照 `w[0]`、`w[1]`，再算新 `w[0]`，于是状态只装载一次。

**归一化约定**：`den_z[0]` 恒为 $1$。`biquad_filter_init` 用 `den_z[0]` 除全部分子与
分母系数；`biquad_filter_set_empty` 直接写 $H(z)=1$ 的单位直通。热路径与
`get_output` / `get_input` 因此都不必再除 `den_z[0]`。

## 设计流程

`s` 域系数到 `z` 域的入口是 `biquad_c2d_bilinear`：代换
$s = 2 f_s \frac{1 - z^{-1}}{1 + z^{-1}}$，把
$H(s) = \frac{B_0 + B_1 s + B_2 s^2}{A_0 + A_1 s + A_2 s^2}$ 映射成
$[b_0,b_1,b_2]$ 与 $[a_0,a_1,a_2]$。它的输出 `den_z` **未归一化**（`den_z[0]` 未必
为 1）；Notch / Peak 直接走这一条路径，随后靠 `biquad_filter_init` 归一化并过闸。
`zpk2sos` 产出的 SOS 则本来就带 $a_0=1$。

部署一律走 `biquad_filter_init`：归一化 → 三道闸 → 状态清零 → 返回 1/0。任一闸失败
即 `biquad_filter_set_empty` 替换为单位直通并返回 0——宁可直通也不要发散。

## 闸门与阈值

`biquad_filter_init` 的三道闸按序执行：

1. **系数有限性**。`den_z[0]` 为零或非有限即拒：零会导致除零；`±Inf` 会让
   `inv = 0`，悄悄部署出分子全零的"静音"滤波器——直通是更安全的兜底。归一化后还要
   全体系数有限：NaN/Inf 分子能通过下面只看分母的 Jury 检查，然后毒化输出。
2. **Jury 三条件**（那两个和用 `sum3f` 求）：
   $|a_2| < 1$、$1 + a_1 + a_2 > 0$、$1 - a_1 + a_2 > 0$。
3. **极点半径裕量**：拒绝任何极点半径 $r > 0.99995$（即 $1 - r < 5\times10^{-5}$）。

第三条存在的直接原因：Jury 允许极点任意贴近单位圆，f32 下 $a_2 = 1 - 2^{-24}$ 照样
通过，滤波器却会振铃 $\ge 10^4$ 样本，所以必须按半径本身再加一道裕量。

### 为什么按半径判而不按 `a2`

`a2` 是两极点的乘积 $a_2 = r_1 r_2$，对**实根对**有盲区：主导极点可能不在 `a2` 里。
例：极点 $0.999999$ 与 $0.85$ 得 $a_2 = 0.85$，能通过任何基于乘积的检查，且
$1 + a_1 + a_2 = 10^{-6} > 0$ 也通过 Jury——只有对主导极点的半径检查能拒掉它。单侧
检查 `a2 > 0.9999` 还会漏掉异号实根对（$a_2 \approx -0.99995$，实根 $\pm 0.99997$）。
所以共轭对看 $a_2 = r^2$，实根用
$r_{\max} = \left(|a_1| + \sqrt{a_1^2 - 4 a_2}\right)/2$ 直接判半径。

半径判定改写成不需要 `sqrtf` 的形式（这条 `init` 路径要保持可在中断上下文中廉价
执行）：实根分支把 $r_{\max} > 0.99995$ 两边平方成
$\sqrt{\mathrm{disc}} > 1.9999 - |a_1|$。判别式本身用 **Dekker 分裂**补偿——宽带
BP/BS 的近实极点对落在距单位圆 $\sim 10^{-4}$ 处，裸 f32 判别式在那里带
$\sim 5\times10^{-7}$ 噪声，足以对合法设计抛硬币。做法是把 $a_1$ 分裂成 $hi + lo$
（$hi$ 用 4097 倍浮点技巧取出），再把平方的舍入误差
$((hi^2 - sq) + 2\,hi\,lo) + lo^2$（$sq = a_1^2$）折回判别式。

### Jury 是教科书契约，不是第二道防线

当前标定下三条 Jury 判据被上面的半径裕量闸蕴含：要让 Jury 单独变红需要一个极点落在
单位圆外，而那种半径必被裕量闸拒。因此它们保留的价值是**教科书写法与独立契约**，
不是第二道有效防线——**不要为了"让 Jury 也能被单独测到"去改实现**。边界档位与这层
含义见 `tests/test_biquad.c` 的「不稳定极点在单位圆外必须被拒」段与「sum3f 补偿」段。

### sum3f：三项补偿求和

`sum3f` 是 TwoSum 式三项和，把每次加法的舍入误差折回。它的收益在 `reset`，不在
Jury 闸：`reset` 拿 $1 + a_1 + a_2$ 做分母，裸 f32 求和可能把真值 $\sim 3\times10^{-8}$
的余量舍成 `0.0f`，于是复位把状态清零，而按 f32 系数的真稳态该是
$equilibrium / (3\times10^{-8})$。折回舍入误差即可在 f32 代价下拿回真余量。

Jury 那条的真余量要么落在 **Sterbenz 精确区**（$|a_1| \in [0.5, 2]$，两次加法都无
舍入），要么对应极点落在 $z \approx 1$ 而被半径裕量闸正当拒掉，所以补偿**从不改变
`init` 的判决**——此处用它与 `reset` 同口径，也为将来单独放宽半径闸时仍按真余量判。
标定（含三种互相印证手段与唯一回归点）见 `tests/test_biquad.c` 的「sum3f 补偿」段。

## reset 契约

`biquad_filter_reset` 是公开结构体上的公开 API，**系数不必先过 `init`**。它把状态调到
常值输入 `equilibrium` 下的稳态：$w[0]=w[1]=w[2]=w_{ss}$，由状态方程
$x = w_{ss}(1 + a_1 + a_2)$ 得 $w_{ss} = x / (1 + a_1 + a_2)$（分母用 `sum3f`）。

三道守卫，任一命中即清零状态，**永不产生 inf/NaN**：

- `equilibrium` 非有限 → 清零（否则 NaN 毒化状态并传到此后每个输出）；
- 分母 $1 + a_1 + a_2$ 为零或非有限 → 清零（如纯积分器，稳态无定义）；
- $w_{ss} = equilibrium / denom$ 溢出成非有限 → 清零。

第三条对应"分母非 0 但极小、`equilibrium` 又极大"的组合，档位见
`tests/test_biquad.c` 的「reset 的 w_ss 溢出分支」段。

## 热路径 static inline

`biquad_filter_update`、`biquad_cascade_update` / `_reset` 与各滤波器族的 per-order
`_update` / `_reset` 全是头文件 `static inline`；级联的节数以编译期字面量传入，循环
边界在编译期折叠。理由：消除 MCU 上每节的函数调用开销，且输出计算与状态更新融合、
`w[]` 只装载一次。代价是两件事必须由调用方承担：热路径刻意**无 NaN/Inf 防护**（每
样本分支开销；非有限输入毒化状态直至 reset，源头清洗），且**不可重入**（同一对象被
ISR 与主循环共享时需关中断或双缓冲）。热路径零 libm；`init` / `reset` 才用
`tanf` / `isfinite` / `fabsf` 等。

## 已知洞与失效模式

- **`den_z[0]` 有限但极大（如 `1e30`）**：本闸只拦 0/非有限，`1e30` 会归一化出
  $b_0 \approx 10^{-30}$ 的近静音滤波器并返回 1。管线内由 `check_cascade_gains` 的
  DC/Nyquist 窗口兜住；直接调用本函数的调用方需自行确认增益量级。
- **非有限输入毒化状态**：热路径不防护（见上），NaN 一路传播直到 reset。
- **`-ffast-math` 使全部有限性闸静默失效**：见下。

### -ffast-math / -ffinite-math-only

fail-closed 的前提是 `isfinite` 不能被编译器折叠成恒真。`-ffast-math` 隐含
`-ffinite-math-only`，编译器据此假设不存在 NaN/Inf，于是把 `isfinite` 折叠成恒真，
全部有限性闸静默失效——实测把 NaN 系数当作 `valid=1` 部署出 NaN 输出；重结合还会
破坏 `sum3f` 与 Dekker 分裂的误差无损性。`biquad_filter.h` 顶部有编译期 `#error`
守卫（`__FAST_MATH__` 与 `__FINITE_MATH_ONLY__`），它既是六个公开头的唯一公共顶点，
守卫放这一处即覆盖全部 translation unit。实测细节与修复口径见 `AGENTS.md` 的
「禁止 -ffast-math」段。

## 为什么不这样写（被否方案）

- **按 `a2` 判半径**：对实根对的主导极点有盲区、漏异号实根对（见上）。改为按半径。
- **`reset` 分母用裸求和**：会把 $\sim 3\times10^{-8}$ 的真余量舍成 0 后误清零。改为
  `sum3f`。
- **判别式用裸 f32 平方**：近单位圆处 $\sim 5\times10^{-7}$ 噪声对合法设计抛硬币。
  改为 Dekker 分裂。
- **半径判定用 `sqrtf`**：`init` 路径要能在中断上下文廉价执行。改为两边平方的等价
  比较。
- **`update` 挪成 out-of-line 函数**：每节函数调用在 MCU 热路径上不可接受。保持
  `static inline`。

## 测试指针

标定表、回归档位与实测统计只维护在 `tests/test_biquad.c`（本文只给结论与指针）：

- 「稳定性裕量：贴近单位圆的极点被拒」与「裕量阈值两侧的紧档位」——`0.99995` 半径
  阈值的两侧边界；
- 「裕量对称性：异号实根对同样被拒」——按半径判而不按 `a2` 的两条反例；
- 「不稳定极点在单位圆外必须被拒」——Jury 教科书契约与"被半径闸蕴含"的现状；
- 「sum3f 补偿」——补偿只在 reset 可观测、Sterbenz 精确区与三种互相印证手段；
- 「reset 的 w_ss 溢出分支」——三道守卫里唯一单独可练的一道；
- 「非有限输入毒化状态」——热路径无防护的文档化语义。
