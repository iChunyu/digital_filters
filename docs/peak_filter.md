# Peak 二阶峰值（peak_filter）

**源文件**：`include/peak_filter.h`、`src/peak_filter.c`
**测试**：`tests/test_peak.c`（标定表、回归档位与实测统计只在此维护，本文只给结论与指针）

固定二阶、单节、无类型与阶数变体的峰值（boost）滤波器。它与 Notch 族**严格互为
倒数**，两族共享同一条设计路径（预畸 → 双线性 → 直写一个 `biquad_filter_t`，不走
`docs/filter_utils.md` 的零极点管线）。本族独有的知识是三件：$g$ 与陷波深度互为倒数的
量纲、统一参数 $d = 1/g$ 及其对判据的影响、以及"极点半径闸通常先触发"。

## 传递函数与参数语义

$$
H(s) = \frac{s^2 + 2\xi \omega_0 s + \omega_0^2}
             {s^2 + 2\xi/g \cdot \omega_0 s + \omega_0^2},
\qquad \omega_0 = 2\pi f_0
$$

$\omega_0$ 是峰值中心角频率，$g > 1$ 是**线性峰值增益**，$\xi > 0$ 是带宽因子。
在 $s = j\omega_0$ 处分子分母的 $s^2$ 项与常数项分别相消，只剩两个一次项之比，得

$$
|H(j\omega_0)| = g, \qquad H(0) = H(\infty) = 1
$$

零点阻尼 $\xi$（宽）、极点阻尼 $\xi/g$（窄）：峰的高度与尖锐度**全部来自极点**——
正好与陷波器相反（那里全部来自零点）。$\xi$ 始终按模拟原型的带宽因子解释，不随
$f_s$ 重标定；数字域的峰宽是 $2\xi f_0/\sqrt{g}$（$\sqrt{g}$ 电平处的全宽）再乘一个
随 $f_0/f_s$ 变化的扭曲因子，因为预畸只保证**中心频率与增益**精确，双线性对整个
频率轴非线性。

$g \to \infty$ 时极点阻尼趋近 0，这是本族唯一会真正发散的方向：它不靠参数闸拦
（`g > 1` 对 $+\infty$ 为真），而由 `biquad_filter_init` 的极点半径裕量闸
fail-closed 拦住（半径裕量 $\approx 2\xi d\tan(\pi f_0/f_s) \to 0$）。$g = +\infty$ 的
极端另有更早的一道：$d = 0$ 使数值闸以 $Q = 0$ 直接拒掉。

对象与 API 与 Notch 逐一对应：`peak_filter_t` 与 `notch_filter_t` 同构（阶数恒定、
单节），`peak_init` / `peak_update` / `peak_reset` 中 `_update` / `_reset` 是头文件
`static inline`，`!valid` 时 update 原样返回输入、reset 为空操作。两族都固定二阶，
因此**不用 X-macro**（对比 Butterworth / Chebyshev 的阶层生成）；热路径无 NaN/Inf
防护、不可重入，见 `docs/biquad_filter.md` 的「热路径 static inline」。

## 与陷波的逐点对偶

$$
H_{\text{peak}}(\xi, g) \equiv \frac{1}{H_{\text{notch}}(\xi,\, 1/g)}
$$

**逐点成立**：模拟域如此，双线性之后依然如此（双线性是与频率无关的有理代换，分子
分母各自被同一组线性组合改写，倒数关系在代换后保持）。代数上直接可见——把
$H_{\text{notch}}(\xi, 1/g)$ 取倒数，分子分母互换即本族的表达式。

在 s 域系数层面，令 $d = 1/g$，两族的系数向量互为**精确交换**
（`biquad_c2d_bilinear` 的入参是升幂 $[s^0, s^1, s^2]$）：

$$
\text{peak.num\_s} = [w_0^2,\; 2\xi \omega_0,\; 1] = \text{notch.den\_s}_{\;\text{任意深度}},
\qquad
\text{peak.den\_s} = [w_0^2,\; 2\xi d \omega_0,\; 1] = \text{notch.num\_s}_{\;\text{深度}=d}
$$

`src/peak_filter.c` 把分母写成 `2.0f * xi * d * w0` 而**不是** `2.0f * xi * w0 / g`，
正是为了让这条交换在 f32 下也成立：前者的表达式形态与 notch 分子里的
`2.0f * xi * g * w0` 同形（同一串乘法，同一舍入路径），除法形态则不保证得到同一位型，
"逐点对偶"就只剩近似。这就是那行代码看起来啰嗦的原因，改它请先看
`tests/test_peak.c` 的 `check_duality`。

到 z 域后两族**各过一次自己的** `den_z[0]` 归一化除法，两个公共比例因子不同，所以
系数只能逐项接近而不是逐位相等；测试正是按这个公共比例因子逐项校验——s 域交换与
z 域归一化两层都钉住。校验方式见 `tests/test_peak.c` 的 `check_duality`，全参数扫掠
里的调用见「频率扫掠 + 对偶不变量：全部落在闸内，且必须精确」段。

## 统一参数 $d = 1/g$：判据必须用 $d$ 而不能用 $g$

本族的全部数值分析都用一个统一参数：**等效陷波深度** $d = 1/g \in (0, 1)$。
$g$ 越大 → 等效陷波越深 → 越难被 f32 承载。设计参数范围闸写成

$$
\xi\, d\, (\omega_0 / K)^2 \ge 5\times10^{-8}, \qquad K = 2 f_s
$$

**为什么必须用 $d$**：由上面的对偶不变量，"$g$ 的 boost 有多难做"与
"$d = 1/g$ 的陷波有多难做"是**同一个问题**。写成 $\xi\, g\, (\omega_0/K)^2$ 会把闸门
随增益放大约 $g^2$ 倍（两个判据之比恰为 $g/d = g^2$），后果是：同一个病态 boost 被
放行，而它的镜像陷波被同一个阈值拒掉——同一件事在族之间得到两个相反判决。

**反直觉但有物理意义**：$Q$ 与 $d = 1/g$ 成正比，所以同样的 $f_0$ 下**高** boost（$g$
大、$d$ 小）反而更容易被拒。与 Notch 的"浅陷波更容易过闸"正好互为镜像。

## 预测式性质与标定口径

这道闸是**预测式**的：在被拒的参数上求 $|H(j\omega_0)|$ 本身就是那个病态运算——峰高
与中心都不再可信（实测偏差是**双符号**的：$\xi = 0.05$、$f_0 = 20$ Hz、$f_s = 48$ kHz、
目标 $g = 10$ 时两侧出现过 7.113 与 11.06，而那一档已被半径闸拒之门外），而
DC/Nyquist 增益无论设计多坏都精确是 1（$z = \pm 1$ 处逐项相消，结构保证），下游
`check_cascade_gains` 察觉不到异常。因此闸只能按参数判，且必须在设计
之前判，而不是"设计完再看一眼响应"。

**标定口径告诫：不要用「f32 系数 + f64 解析求值」做标定。** 那个口径忽略了 f32 状态
递推的舍入，而这里的状态量 $|w| \approx 1/|D(e^{j\theta_0})|$ 会到 $10^7$ 量级，其
ulp 本身就和输出同量级——系数误差只是病态的一半，另一半在状态里。口径、标定表、双
符号偏差的实测档位与两条闸的先后关系只在 `tests/test_peak.c` 的
「数值闸边界：Q = xi\*d\*(w0/K)^2 跨过 5e-8」段维护，本文不复制表格。

## 半径闸刻度与两条闸的先后

极点阻尼是 $\xi d$，极点半径裕量约为 $2\xi d \tan(\pi f_0/f_s)$；
`biquad_filter_init` 的半径裕量闸要求它不小于 $5\times10^{-5}$。解出增益上限：

$$
2\xi d \tan\!\left(\frac{\pi f_0}{f_s}\right) \ge 5\times10^{-5}
\;\Longleftrightarrow\;
g \le 4\times10^{4}\,\xi\,\tan\!\left(\frac{\pi f_0}{f_s}\right)
$$

这就是本节的实用上限刻度的来历——它是**导数**，不是独立标定的常数。

以 $r = \tan(\pi f_0/f_s)$ 计，两道闸的阈值分别是
$r_q = \sqrt{5\times10^{-8}/(\xi d)}$（数值闸）与 $r_r = 2.5\times10^{-5}/(\xi d)$
（半径闸）；$r_q > r_r \iff \xi d > 0.0125$。于是：

- $\xi d < 0.0125$（常见参数）时**半径闸先触发**，本族的实际可用上限主要由极点半径
  决定，即上面那条 $g \le 4\times10^4 \xi \tan(\pi f_0/f_s)$；
- $\xi d > 0.0125$ 时数值闸才是先触发的那道。

这与 Notch **相反**：notch 的极点阻尼是 $\xi$（与 $g$ 无关），$r_q > r_r \iff \xi > 0.0125\,g$，
数值闸在绝大多数参数下更紧。两条闸的先后关系、两侧档位与阳性对照
见 `tests/test_peak.c` 的「数值闸边界」段。

## 浅到等同不 boost：$d \ge 0.9999$（$g \le 1.0001$）按直通部署

浅于 0.001 dB 的 boost 等同恒等，按直通部署（`valid = 0`）比烧一个高 Q 节划算。
判据写成 `!(d < PEAK_D_MAX)`——**等号即拒**；$g = 1$ 更早被参数闸的 `g > 1` 拦掉，
$g = +\infty$ 由上文的 $Q = 0$ 拦掉。三条边界与 Notch 的 $g \ge 0.9999$ 严格镜像
（f32 下 `1.0f / 1.0001f` 恰好舍入到 `0.9999f`，正落在阈值上）。

## reset 与 $w_{ss}$ 量级

与陷波器同理：DC 增益为 1，稳态状态量 $w_{ss} = e/(1 + a_1 + a_2)$ 在
$10^5 e$ 量级（$f_0 = 20$ Hz、$f_s = 48$ kHz 时约 $1.5\times10^5 e$，推导与档位见
`docs/notch_filter.md` 的「reset 与 $w_{ss}$ 量级」）。复位后最初几个输出在 f32 下带
绝对误差、随后收敛，是结构固有，不是 bug。守卫（分母为零/非有限、$w_{ss}$ 溢出 →
清状态，永不产生 inf/NaN）在 `biquad_filter_reset` 层，见 `docs/biquad_filter.md`
的「reset 契约」。

## 已知边界：被拒是预期行为

- **近 DC / 近 Nyquist / 极窄带 / 高增益**的设计返回 `valid = 0`（直通）：主因是
  f32 系数量化（这里通常先撞极点半径裕量），不是算法错误。边界**非单调**，以 `valid`
  为准。
- **高 boost 上限由半径闸给**：$g \le 4\times10^4 \xi \tan(\pi f_0/f_s)$（见上）。
- **被拒 ≠ 静默失真**：这道闸是预测式的，意义正是"不在明知会失真时还点头"。
- $g$ 略大于 1（如 1.001）是合法设计（约 0.0087 dB boost），别把它和 $g \le 1.0001$
  的直通档混为一谈。

## 测试指针

标定表、回归档位与实测统计只维护在 `tests/test_peak.c`（本文只给结论与指针）：

- `check_duality` + 「频率扫掠 + 对偶不变量：全部落在闸内，且必须精确」——对偶不变量
  的系数级校验（s 域精确交换、z 域按公共比例因子逐项校验），全频点扫掠调用；
- 「基本设计：fs=1kHz, f0=50Hz, xi=0.05, g=10 (+20 dB)」、「增益扫掠」、
  「xi 扫掠」——峰高 $\approx g$、DC/Nyquist 精确为 1、窄带语义；
- 「数值闸边界：Q = xi\*d\*(w0/K)^2 跨过 5e-8」——阈值标定（f32 系数 + f32 状态
  递推的时域仿真、邻域取最坏）、双符号偏差、半径闸刻度、两条闸的先后与"高 boost
  更容易被拒"的档位；
- 「g 边界：浅到等同不 boost → 直通（与 notch 的 g ≥ 0.9999 镜像）」——$g = 1$ /
  $g = 1.0001$ / $g = 1.001$ 三点；
- 「参数闸：非法输入一律 valid=0 且 num_sections 清零」——含 NaN / +Inf，其中
  $g = +\infty$ 由数值闸拒；
- 「reset：DC 稳态（峰值滤波器 DC 增益同样是 1）」。

## 为什么不这样写（被否方案）

- **判据写成 $\xi g (\omega_0/K)^2$**：闸门随增益放大 $g^2$ 倍，放行病态 boost 而拒掉
  它的镜像陷波（见上）。
- **分母写 `2.0f * xi * w0 / g`**：s 域系数不再与 notch 分子逐位同形，"逐点对偶"只剩
  近似。改为 `2.0f * xi * d * w0`。
- **走 `design_filter` / `zpk2sos`**：二阶节没有配对问题，多付容量闸、两个容差、两条
  收尾不变量与增益折叠，收益为零。
- **$g \le 1.0001$ 也烧一个节**：数学上就是恒等（浅于 0.001 dB），只换来数值风险。
- **用 f64 解析求值做阈值标定**：忽略 f32 状态舍入，低估病态量级，会定出乐观的阈值。
- **入口闸写 `g <= 1.0f`**：NaN 比较恒假，会把 NaN 放行。
